Reflection Points — 18/08/2026

1. The unit of length used in code is usually **pixels**.
2. Programming languages provide **sensible default values** when values are not explicitly given.
3. When the **centre and length** of a shape are given, we first find its starting point, usually the **upper-left corner**.
4. If the centre is `(cx, cy)` and the length is `l`:
  - **Upper-left:** `(cx - l/2, cy - l/2)`
  - **Lower-left:** `(cx - l/2, cy + l/2)`
  - **Upper-right:** `(cx + l/2, cy - l/2)`
  - **Lower-right:** `(cx + l/2, cy + l/2)`
5. `POM` stands for **Project Object Model**.
6. The `.gitignore` file tells Git which files or folders should be **ignored** and not tracked or pushed to GitHub.
7. Inside the `src` folder, we generally have **main** and **test**.
8. The `main` folder contains the code that is shipped with the application, while `test` contains testing code.
9. Inside `main`, the `java` folder contains the actual source code.
10. The `java` folder is named this way because a project can potentially contain code written in **other languages** as well.
11. The `resources` folder can be used to store files that need to be **bundled with the application**.
12. An **instance field** belongs to an individual object, so every object has its own separate copy.
13. A **static field** belongs to the class itself, so all objects share the same copy.
