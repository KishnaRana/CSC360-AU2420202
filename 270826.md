Reflection points - 27/08/2026
1. **Swing** is Java's built-in toolkit for creating desktop GUIs such as windows, buttons, menus, and other components. Since it is written in Java, it can work across different operating systems.
2. `mvn javafx:run` is a Maven command used to **build and launch a JavaFX application** using the JavaFX Maven plugin.
3. The Maven `install` phase copies the built project into the **local Maven repository** on your computer so that other projects can use it as a dependency.
4. A **JAR (Java Archive)** is a ZIP-like file that contains compiled Java code (`.class` files) along with other resources such as images and configuration files.
5. A **`.class` file** is the compiled version of a `.java` file. It contains **bytecode**, which is read and executed by the JVM.
6. A **package** in Java is used to group related classes together. It helps organize code and prevents naming conflicts.
7. A **JAR** is the final packaged output of a project, containing the compiled code and required resources in one file.
8. `pom.xml` is the **configuration file for Maven**. It contains project dependencies, build settings, and instructions for creating the JAR.
    - **`pom.xml` = recipe**
    - **JAR = finished dish**
9. **Integration** means combining different pieces of code or systems so that they work together properly. For example, connecting an application to a database or combining code written by different developers.
10. **Deployment** means taking a completed application and putting it on a server or platform so that real users can access and use it.
11. `cd` stands for **Change Directory**. It is a terminal command used to move from one folder to another.
12. `git pull` downloads the latest changes from a remote Git repository and merges them into the local project.
13. The basic flow is:
  `GitHub → git pull → Local Project`
14. A **character set** defines the characters a computer can represent.
- **ASCII** mainly supports English characters.
- **Unicode** supports characters from many languages and symbols.
- **UTF-8** is the most commonly used Unicode encoding.
15. **JUnit** is a Java framework used for testing code.
- It helps check whether a program works correctly.
- Tests can **pass or fail** based on the expected result.
