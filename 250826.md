Reflection Points — 25/08/2026

1. **Validate** means checking whether the project is correct and ready for the next stage.
2. The Maven **lifecycle** follows an ordered sequence:
  - `clean`
  - `validate`
  - `compile`
  - `test`
  - `package`
  - `verify`
  - `install`
  - `site`
  - `deploy`
3. A Java **class file** contains **bytecode**.
4. The **JVM (Java Virtual Machine)** reads the bytecode and converts it into machine-level instructions that the computer can execute.
5. **Accessible** means something designed to be usable by people with different abilities, including people who cannot see.
6. A **process** is a program that is currently running.
7. A **thread** is the smallest unit of execution within a process.
8. One process can contain **multiple threads**, allowing different tasks to run within the same program.
